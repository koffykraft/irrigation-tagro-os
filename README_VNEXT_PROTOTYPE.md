# vNext UI Prototype

This branch contains a separate, non-production UI prototype at `ui-vnext-prototype.html`.

It intentionally does not replace `location-map.html` or the V16 CAD/runtime stack.

Purpose:

- test a fresh map-first interaction model;
- use a top-right first-finger work control;
- allow partial or full field drawing;
- project the same objects into a Drawing surface without export/recreation;
- show AI design suggestions as reversible proposals;
- separate BOM engineering requirements from Jain/generic product resolution.

The prototype is not evidence that the production CAD tools are wired to the new UI. Existing V16 functionality remains authoritative until an approved integration step is completed and runtime-tested.
