## 14. TAGRO OS DOCTRINE THAT APPLIES TO THIS BUILD

Lifecycle:

**REALITY → OBSERVATION → EVIDENCE + PROVENANCE → FARM KNOWLEDGE → PLANAR INTERPRETATIONS → DESIGN OPTIONS → DECISION → PHYSICAL IMPLEMENTATION → OPERATIONAL EVENTS → NEW REALITY**

Mothership:

- Farm/system is durable host.
- Capabilities are replaceable docks/modules.
- Kernel has no domain logic.
- Providers/maps/weather/AI/databases remain replaceable.

Planar:

- One fact/event supports many views without duplicating truth.
- State is derived from events.
- Corrections preserve history.
- Provenance is material.

Flux:

- Designs, observations, components and decisions are versioned/redesignable.
- Recalculate the smallest affected scope.
- Installed reality is never silently overwritten.

Ripple questions:

1. What changed?
2. What depends on it?
3. What remains valid?
4. What must recalculate?

Shadow:

- Failed/poor designs are retained as institutional memory.
- Equivalent failures add evidence rather than being forgotten.

Provenance maturity:

**Observed → Measured / Described / Inferred → Confirmed → Proposed → Accepted → Installed**

Inferred is never silently promoted to Confirmed.

Core TAGRO design tests are **Honesty** and **Cleanliness**: represent reality accurately and leave the system understandable for the next person.
