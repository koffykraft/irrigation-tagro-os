Governing query rule

There is no universal irrigation questionnaire. The system identifies the farmer's present task, reuses existing evidence, defaults to SUB_MINIMUM information effort, asks only consequential questions, respects hard engineering gates, and offers deeper investigation only where it earns value.

Key physical relationship

Application device → outlet / plant demand point → lateral → submain → main → operating group → pump / power → water source.

Irrigation is one dock on Farming Systems. Soil, crop, weather, labour, finance, access, machinery and other shared facts remain shared mothership knowledge.

Implementation rule

Pages are planar solution-arrival surfaces. Maps, tiles, colors, sizing, sidebars, page layouts, databases, AI providers, drawing engines and calculation implementations are replaceable adapters. No implementation choice may become hidden domain doctrine.
